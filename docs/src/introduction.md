# Introduction

knotra is a local-first, lightweight GUI for developers who manage multiple
Git and Jujutsu repositories in parallel.

## What knotra does

- Shows you the health of all your repositories on one screen.
- Lets you fetch, pull, and switch context across repositories in bulk.
- Creates release snapshots (tags / bookmarks) atomically, with rollback.
- Logs every operation so you can audit what happened and why.

## What knotra does not do

knotra is not a general-purpose Git GUI. It does not replace tools like
GitKraken or Fork for single-repository deep work. It fills the gap between
those tools and the command line for multi-repository orchestration.
