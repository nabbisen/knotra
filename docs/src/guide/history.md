# History

Searchable, expandable log of all operations, headed "What happened" on screen. Entries
persist across restarts, and each one shows the time it ran in your computer's own time
zone. Click **Show details** to see per-project outcomes, commands executed, stderr
excerpts, and recovery hints — the same control then reads **Hide details**. Click
**Copy log** to copy a full log entry to the clipboard; the copied text always uses UTC,
labelled, since it is meant to be shared with people in other time zones.
