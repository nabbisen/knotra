# Keyboard Shortcuts

| Shortcut | Action |
|---|---|
| `Ctrl+R` / `⌘R` | Refresh all project statuses |
| `Ctrl+K` / `⌘K` | Open Context Switch |
| `Ctrl+T` / `⌘T` | Open Freezer (Tag modal) |
| `Ctrl+/` / `⌘/` | Focus search box (returns to Dashboard) |
| `Esc` | Close open modal or dialog |

## Dashboard — selection mode

| Key | Action |
|---|---|
| `f` | Fetch selected projects |
| `p` | Smart Pull selected projects |
| `t` | Open Tag modal for selected projects |
| `b` | Open Switch Branch modal for selected projects |
| `Space` | Toggle selection on focused card |

Navigation is fully keyboard-accessible via tab order in every screen.
