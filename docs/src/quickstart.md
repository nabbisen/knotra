# Quick Start

## 1. Build

```sh
cargo build --release -p knotra-app
```

## 2. Run

```sh
./target/release/knotra
```

## 3. Add repositories

Open **Settings → Add Project** and provide the path to a local Git or jj
repository. Repeat for each repository you want to monitor.

## 4. Refresh

Press **⌘/Ctrl+R** or click **Refresh** on the Dashboard to load the current
status of all projects.

## 5. Explore

- **Dashboard** — card-grid overview of all repositories.
- **Sync** — bulk fetch and Smart Pull.
- **Context** — switch branch or change-set across repositories.
- **Freezer** — create release snapshots atomically.
- **History** — browse and copy operation logs.
